# Vilano Studio — mockup

Sitio estático basado en el manual de marca: Chocolate `#30241D`, Crema `#F2E9DB` y Champagne `#B89A68`, con blanco y un acento bronce discreto.

- `index.html`: Vilano Studio
- `salon.html`: Vilano Beauty Studio (Local 2)
- `barber.html`: Vilano Barber Studio (Local 1)

Abrí `index.html` para recorrer el mockup. Vilano Beauty abre la agenda alojada de AgendaPro en otra pestaña, sin backend propio. Vilano Barber queda sin reservas hasta que se cree esa sucursal en AgendaPro.

Al momento de esta prueba, AgendaPro muestra “Por el momento no aceptamos reservas en línea”. Hay que habilitar las reservas de Beauty en la cuenta para que el flujo quede operativo.

Las fotografías y tipografías se cargan desde servicios externos, por lo que se necesita conexión a internet para verlas.
