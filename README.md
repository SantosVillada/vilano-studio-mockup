# Vilano Studio — mockup

Sitio estático basado en el manual de marca: Chocolate `#30241D`, Crema `#F2E9DB` y Champagne `#B89A68`, con blanco y un acento bronce discreto.

- `index.html`: Vilano Studio
- `salon.html`: Vilano Beauty Studio (Local 2)
- `barber.html`: Vilano Barber Studio (Local 1)

Abrí `index.html` para recorrer el mockup. Los botones llevan a las páginas de cada espacio. Las reservas todavía son ilustrativas; falta conectar los enlaces de AgendaPro de cada sucursal.

Las fotografías y tipografías se cargan desde servicios externos, por lo que se necesita conexión a internet para verlas.
