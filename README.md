# Vilano Studio — mockup

Landing page estática para presentar las dos sucursales:

- `index.html`: Vilano Studio
- `salon.html`: Vilano Beauty
- `barber.html`: Vilano Barber

Abrí `index.html` para recorrer el mockup. Los botones llevan a las páginas de cada espacio. Las reservas todavía son ilustrativas y no conectan con Wonoma.

Las fotografías y tipografías se cargan desde servicios externos, por lo que se necesita conexión a internet para verlas.
